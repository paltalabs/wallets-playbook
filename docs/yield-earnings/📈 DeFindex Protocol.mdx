# DeFindex Protocol

## Introduction

DeFindex is a yield aggregation protocol built on Stellar/Soroban that simplifies DeFi access for wallets and their users. The protocol enables the creation of tokenized vaults that automatically distribute user funds across multiple yield-generating strategies, handling the complexity of yield optimization behind the scenes.

With DeFindex, vault managers can rebalance positions, auto-compound earnings, and optimize returns without requiring additional user signatures. This makes it ideal for wallets looking to offer yield-generating accounts without building deep DeFi expertise in-house.

- [🌐 DeFindex Website](https://defindex.io)
- [📖 DeFindex Documentation](https://docs.defindex.io)
- [💻 DeFindex GitHub](https://github.com/paltalabs/defindex)

## Why Integrate with DeFindex

Integrating DeFindex brings several strategic benefits to wallet providers:

- **Simplified Yield Access:** Offer users yield-generating accounts without managing complex DeFi integrations yourself. DeFindex handles strategy allocation, rebalancing, and compounding automatically.
- **Diversified Strategies:** Access multiple yield sources through a single integration. Vaults can distribute funds across lending protocols like Blend, liquidity pools, and other DeFi opportunities.
- **Transparency & Security:** All vault operations are executed on-chain with full transparency. Users can verify exactly where their funds are allocated and how returns are generated.
- **Revenue Sharing:** DeFindex supports flexible monetization models, allowing wallets to earn a share of the yield generated by their users.
- **Easy Integration:** Multiple integration options available including TypeScript SDK, .NET SDK, and REST API, making it accessible regardless of your tech stack.

## How to Integrate DeFindex

1. **Choose Your Integration Approach:**
   DeFindex offers multiple ways to integrate:
   - **TypeScript SDK:** For JavaScript/TypeScript applications
   - **.NET SDK:** For C#/.NET applications
   - **REST API:** For any platform that can make HTTP requests

   📖 [Wallet Developer Documentation](https://docs.defindex.io/api-integration-guide/api)

2. **Define Your Revenue Model:**
   Decide how to monetize the integration. You can pass 100% of yields to users or configure fee-sharing arrangements where your wallet earns a percentage of generated yields.

3. **Design the User Experience:**
   Keep the interface simple for users. Consider showing:
   - Current vault balance and deposited amount
   - Current APY and historical performance
   - Underlying strategies and risk information

   DeFindex provides APIs to fetch real-time yield data and vault performance metrics.

4. **Technical Integration:**
   - Classic Stellar wallets (G addresses) can interact with DeFindex vaults
   - If using Horizon, you'll need an [RPC endpoint](https://developers.stellar.org/docs/data/apis/rpc) for Soroban transactions
   - Vault shares are tokenized, making balance tracking straightforward

   📖 [Technical Integration Guide](https://docs.defindex.io/api-integration-guide/api)
